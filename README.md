## About the Utility

Welcome to Bloxburg Script is a compact Roblox web tool for Bloxburg users who want several gameplay helpers available through one script. It operates through an executor and focuses on making repetitive tasks easier while providing direct access to controls, hotkeys, and basic configuration options.

Instead of relying on a complex interface, the project keeps its assistance features practical and lightweight. Targeting behavior, auto-collect support, on-screen activity feedback, and configurable range values are included so users can adapt the script to their preferred play style and session requirements.

## Included Features

- Assisted aimbot targeting for in-game aiming
- Auto-collect support for recurring pickup tasks
- User-defined hotkeys for quicker feature control
- Configurable range values for behavior adjustments
- Visible status information showing current activity
- Compact execution with a lightweight script design
- Straightforward settings for setup and customization
- Functionality focused on Roblox Bloxburg gameplay use
